# 以管理目录替代产品项目

产品以调用方传入的本地绝对目录作为登记资源的管理单位，而不再使用具名项目及项目前缀；分别选定的父子目录互相独立，同一目录的符号链接别名视为同一目录。目录限定资源操作范围以避免误操作，但不是安全隔离边界。MCP 客户端复用本机服务，每次目录级操作显式传入路径；本阶段只考虑一个本地运行时，不支持跨网使用。

这取代按项目名或 prefix 登记的方案：用户以项目所在目录使用统一容器管理入口，希望避免不同目录的资源互相影响，而不再维护项目名。旧版本未正式启用，不要求迁移旧项目数据；目录搬迁后也不转移原有归属，新目录重新构建，旧资源保留。
